# SHIELD NEWS design

Reference: design-md / voltagent/awesome-design-md, Binance design system (MIT).

- Canvas #0b0e11; card #1e2329; elevated/hairline #2b3139.
- Main type #eaecef; readable secondary #929aa5; primary #fcd535; active #f0b90b; primary text #181a20.
- Flat surfaces; no glows/glass/heavy shadows. Yellow identifies the brand, selected filters, key heading and primary actions.
- Original header/page/panel/list/detail/tag structures are retained and adapted.
- 1280px centered container, 24–32px gutters, 4px spacing rhythm, 6/8/12px radii. 8/4-style feature split with dense headline rail.
- System/Inter Japanese-capable font stack replaces unavailable licensed Binance fonts. Dates use tabular numerals. Display 36–60px, titles 20–27px, body 13–15px.
- Compact header; mobile menu and single-column cards; focus rings and reduced-motion support.
- Light #fafafa footer ends the dark editorial page.
- Fictional samples are explicitly marked. Original source and publication date are never replaced with invented publisher/author identities.
